# Orquestra Live — Site Comercial

## O que é
Site institucional/comercial de vendas da plataforma Orquestra Live (não é o app da plataforma em si — esse é outro repositório).

## Stack
- Next.js 16 + TypeScript
- Vercel (deploy)
- GoDaddy (DNS)

## Status
Em produção.

## Go-to-market associado a este site
- SEO / Google Ads
- Instagram, LinkedIn
- Prospecção direta
- Verba de mídia paga estimada: ~R$1.000/mês

- Deploy automático via push para `main` (Vercel)
